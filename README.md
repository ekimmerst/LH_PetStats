<h1 style="color: #d9a94b;">LH PetStats</h1>

<p>A small loyalty readout for hunter pets, placed beside Blizzard's pet portrait. It gives that useful bit of pet information a home in the existing UI.</p>

<h2 style="color: #73c9c4;">What it shows</h2>

<ul>
  <li>The pet's current loyalty rank beside its portrait.</li>
  <li>An optional gold bar in the LH ExpBar style, with a tooltip explaining the rank.</li>
  <li>Independent switches for the rank text and bar.</li>
</ul>

<p>The bar shows the current rank out of six. It is not pet XP or progress toward the next loyalty rank. The display appears only for hunter pets with loyalty data.</p>

<h2 style="color: #c78be6;">Settings</h2>

<p>Open <strong>Options → AddOns → LH Tweaks → LH PetStats</strong> to choose what is shown. The options are saved per character.</p>
